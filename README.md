# henriquefy

Claude Code skills that know how [Henrique Bastos](https://github.com/henriquebastos) (HB Network)
writes Python, designs APIs, models objects and tests, and that apply it to your code.

```
uvx henriquefy install     # writes the henriquefy skill into ~/.claude/skills/
```

Then, in Claude Code: `/henriquefy`, or just ask "what would Henrique do here?".

```
uvx henriquefy check path/     # mechanical findings, each mapped to a principle, no Claude needed
uvx henriquefy grade path/     # Nota mecânica: deterministic, never his verdict
```

Status: Phase 5. `ask`, `check`, `grade` and `transform` are live over 25 principles, 15 patterns,
four course digests and 14 repo digests. The full plan is in [PLAN.md](PLAN.md). Watch the
originals: [HB Network on YouTube](https://www.youtube.com/@hbnetworkoficial).
