## Principles

- a-interface-e-o-que-importa | api | judgment | Design an API from its boundary inward.
- camada-de-servico | modeling | judgment | Business rules live in domain objects and in a service layer that the views call; views parse the request, call one service operation, and build the response.
- chame-a-base-explicitamente | modeling | partial | When a subclass defines `__init__`, the base class's `__init__` does not run on its own; the subclass method replaces it.
- codigo-linear | readability | partial | A function reads top to bottom with one way in and one way out: input, processing, output, in that order.
- componha-em-vez-de-herdar | modeling | partial | When an object needs a behavior that varies, give it a collaborator that carries the behavior instead of subclassing it.
- configuracao-fora-do-codigo | project | partial | Settings and credentials live outside the code, read in one place with a declared type and a default.
- deixe-o-codigo-descansar | simplicity | judgment | Before refactoring, let the code sit until you understand it.
- erro-antes-da-falha | testing | judgment | An error and a failure are different, and the error comes first.
- erros-na-fronteira | errors | partial | The domain raises named exceptions and knows nothing about HTTP.
- escolha-a-regra-mais-simples | simplicity | judgment | When the domain leaves a choice open, take the rule that needs the least code and the least state, even when a richer rule would be more faithful to the original specification.
- evite-ciclos-busque-a-arvore | modeling | partial | Dependencies between objects, and between modules, point one way.
- execute-antes-de-ler | testing | partial | Never refactor code you cannot prove still works.
- httpstatus-em-vez-de-numeros-magicos | api | mechanical | Never write an HTTP status code as a bare integer.
- hypermedia-como-maquina-de-estados | api | judgment | When a resource has states, the server owns the transitions and tells the client which ones are available now, as links in the representation.
- inicialize-o-estado-no-init | modeling | partial | Every attribute an instance will ever have is assigned in `__init__`, even when its first useful value only arrives later.
- nao-projete-a-generalizacao | simplicity | judgment | Do not design the abstraction up front.
- o-codigo-e-a-interface | readability | partial | The code itself, as read by its callers, is the design artifact: the names of classes and methods, the messages a test sends, the sentence a line of code forms.
- o-verbo-comanda | api | partial | The URI names the resource and the HTTP method says what to do with it.
- objeto-e-um-processo | modeling | judgment | An object is a process that provides a service.
- pense-localmente | modeling | judgment | Model and build from the parts, not from the whole.
- postergue-decisoes | modeling | judgment | Do not decide what you do not yet understand.
- pragmatismo-sobre-pureza | simplicity | judgment | Treat design choices as trade-offs with costs and benefits, never as right versus wrong.
- prefira-excecoes-a-booleanos | errors | partial | When an operation can end in more than one way that the caller must tell apart, name each outcome as a specific exception instead of returning a boolean and branching on it.
- recurso-nao-e-entidade-de-banco | api | judgment | A resource is a projection of something in the world that is useful to a consumer in some context, not a row in a table.
- representacao-nao-e-codificacao | api | partial | A resource has representations, and a representation has encodings.
- superficie-de-contato | modeling | judgment | Two parts should meet on a small contact surface.
- taft | testing | judgment | Test all the time, and test automatically.
- teste-primeiro-das-folhas | testing | partial | Write the test before the code, and start with the leaves of the system: the entities with one responsibility and few relations.
- uma-responsabilidade-por-identidade | modeling | partial | Each entity owns exactly one responsibility, stated in one sentence, and holds only the state that responsibility needs.
