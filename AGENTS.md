## Repository Overview

`henriquefy` is a Python package (>=3.12, `uv`, hatchling, no runtime dependencies) that ships Claude Code skills applying Henrique Bastos's Python, OO, API-design and testing practices. Layout:

- `src/henriquefy/` — the CLI (`cli.py`: `install`, `update`, `watch`, `check`, `grade`), plus `check/`, `grade/`, `ingest/` and `watch.py`.
- `kb/` — the knowledge base the skill reads: principles, patterns, repo and course digests. `kb/INDEX.md` is generated.
- `skills/` — the skill sources (`henriquefy`, `henrique-ingest`, `henrique-watch`).
- `state/`, `evals/`, `tests/` — ingest state, transform evals, pytest suite.
- `PLAN.md` — design and phase history; read it before structural changes.

`kb/`, `skills/`, `evals/` and `sources/` hold verbatim excerpts and are excluded from ruff; never reformat them. `sources/` is local and never committed.

## Hard Rules

- **Never push to `main`.** Changes land through a reviewed pull request. Force-pushing a feature branch is fine (prefer `--force-with-lease`).
- **Never leave a process you started running.** Run one-shot, foreground commands (`uv run pytest -q`, never a watch mode), give long commands a timeout, and before reporting done check that nothing you started is still alive (`pgrep -fl 'pytest|yt-dlp|ffmpeg'`).
- **New env vars or settings must reach every place CI reads them.** CI is `.github/workflows/ci.yml` and `release.yml`; update both when a change needs a new variable or secret.

## Code Style

- No unnecessary comments. Names carry the meaning; comment only a non-obvious *why*, in one terse line.
- Never commit secrets or real credentials.
- After adding a helper, `rg` for existing code that does the same thing and reuse it instead of leaving duplicates.
- Use unique values per test: never hard-code a shared name, id or path across tests; use `tmp_path` and per-test data.

## Testing Policy

- Write the failing test before the code, never after. A test shaped to fit finished code restates the implementation.
- Prefer end-to-end tests: drive the CLI the way `tests/test_install.py` and `tests/test_check.py` do, and check the observable result (exit code, files written).
- For logic that cannot be reached that way (parsers, scoring math, rule detection), first list how it can fail, write a test per failure mode, then implement.
- Do not write tests for constants, defaults, `__repr__`, or mocks that return what they were told to. Delete them when found. Coverage percentage is not a goal.

## Commit and PR Guidance

- Keep commits atomic, focused and descriptive. Include regenerated files (`kb/INDEX.md`) with the change that needs them.
- Run the CI gate before every push and let it pass; never push with failing or skipped checks.
- Do not add a `Co-Authored-By:` trailer or a "generated by" line for any agent or AI tool, in commits or PR text.
- Never commit screenshots or PR media. Save them outside the git tree and share the path so the human attaches them.

## AI Assistant Guidance

- Change only what the task requires, and finish it. Match neighboring code instead of introducing new patterns; leave unrelated cleanups for their own PR.
- Validate assumptions against this repo's `pyproject.toml` and `PLAN.md`, not other repositories' conventions.
- Right-size subagent models; when unsure between tiers, pick the lower one:
  - **Haiku** — lookups, grep/find, running a command and reporting output, mechanical edits.
  - **Sonnet** — multi-file edits with a settled design, tests for an understood module, bounded diff review, PR descriptions.
  - **Opus** — architecture, non-trivial planning, debugging with an unclear cause, cross-subsystem refactors.

## Preferred Commands

All from the repo root; these are exactly what CI runs.

```sh
uv sync --group dev
uv run ruff check .
uv run ruff format --check .      # uv run ruff format . to fix
uv run pytest -q
uv run python -m henriquefy.ingest.build_index --check   # regenerate kb/INDEX.md without --check
uv run henriquefy check path/     # mechanical findings
uv run henriquefy grade path/     # mechanical grade
```
